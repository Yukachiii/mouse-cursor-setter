# Cursor Scheme Installer

Windows用の `.ani` / `.cur` カーソルセットを、フォルダのドラッグ＆ドロップだけで適用・登録するツールです。

## 使い方

1. Release の ZIP を展開します。
2. カーソルファイルが入ったフォルダを `CursorSchemeInstaller.bat` にドラッグ＆ドロップします。
3. フォルダ名が、そのまま Windows の「マウスのプロパティ → ポインター → デザイン」に登録されます。
4. カーソル設定はその場で反映されます。

管理者権限は不要です。

## 対応

- Windows 10 / 11
- `.ani`
- `.cur`
- 日本語のフォルダ名・ファイル名
- 英語名と一般的な日本語名のカーソル役割
- テーマ名などの接頭辞が付いたファイル名

例:

- `月音こな_通常選択.ani`
- `月音こな_待ち状態.ani`
- `月音こな_斜めに拡大／縮小１.ani`
- `Arrow.cur`
- `Wait.ani`

対応するファイルが存在しない役割は、現在のカーソル設定を維持します。

## ファイル

- `CursorSchemeInstaller.bat`  
  フォルダをドラッグ＆ドロップする起動ファイルです。

- `CursorSchemeInstaller.ps1`  
  カーソルの判定、レジストリ登録、Windowsへの反映を行います。

## 注意

カーソルファイルを後から移動・削除すると、そのデザインから参照できなくなります。
登録後も元のカーソルフォルダは同じ場所に残してください。
